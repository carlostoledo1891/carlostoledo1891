### Carlos Toledo

**Independent exact certification of machine-generated mathematics — exact arithmetic, no code shared with the claimant, refusal as a verdict.**

I decide mathematical claims, mine and other people's, in exact rational or outward-rounded interval arithmetic, without running the claimant's code. I publish refusals as well as verdicts.
